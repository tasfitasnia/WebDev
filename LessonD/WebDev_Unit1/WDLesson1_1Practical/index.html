Web Technologies

HTML

HTML stands for Hyper Text Markup Language. HTML is a language used to describe what a web page looks like. It is like the blueprint of majority of the webpages you visit.

CSS

CSS stands for Cascading Style Sheets. It allows you to create the layout and the design of the web pages. While the HTML provides the structure of the website, CSS acts like the "decoration" and makes the layout look appealing.

JavaScript

JavaScript is a higher level programming language as the core technology of the WWW (World Wide Web), just like HTML and CSS. It enables the developers to build the dynamics and makes the website interactive.
